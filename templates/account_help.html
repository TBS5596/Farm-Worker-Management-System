Cannot sign in?

{{ org_name }}

There is no automatic password reset on this system, and that is on purpose: it runs on the farm's own machine with no mail server, so a reset link has nowhere to go and anything else would just be a second, weaker password on the account that reaches payroll. Two things do work.

1 Ask another administrator

Any administrator can reset your password from Users in the dashboard. You will be asked to choose your own the moment you sign in with what they give you.

{% if admin_count <= 1 %}

This farm has only one administrator account, so there is nobody else to ask. Use the second route below, and consider adding a second administrator afterwards.

{% endif %}

2 Reset it on the office machine

If nobody can get in at all, run this where the system is installed: 

python tools/reset_admin.py

It prints a new password once and makes whoever uses it choose their own straight away. No worker, attendance record or payroll row is touched — do not delete the records file to get back in, because that is the farm's attendance and payroll.

Looking for a worker's forgotten PIN instead? That is on the clock-in screen, or any supervisor can reset it from the Workers page.
