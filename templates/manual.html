System Manual

Use this manual for day-to-day operations, onboarding, attendance verification, and troubleshooting.

1) Quick Start Checklist
  • Sign in as admin from the login page.
  • Open Workers and create at least one active worker with a unique PIN.
  • Open CCTV and confirm your camera source is available.
  • Test a worker Clock In and verify it appears in Attendance.
2) Worker Onboarding (Example)

Example: Add a new worker named "Moses Banda".

  1. Go to Workers and click Add Worker.
  2. Enter name, phone, NRC, department, and set status to active.
  3. Create a unique PIN (at least 4 digits).
  4. Click Save Worker. A 4-digit worker ID is generated automatically.

3) Attendance Capture (Clock In / Clock Out)

Example: Worker "0001" clocks in at start of shift.

  1. On the login page, choose Worker Clock-In.
  2. Enter Worker ID and PIN, then choose Clock In.
  3. System validates credentials, checks face/eyes from camera, then captures photo.
  4. Record is written to Attendance and visible in the Attendance page.

4) Edit and Reset Operations (Example)

Example: Update a worker phone number and reset PIN.

  1. In Workers, click the Edit icon on the worker row.
  2. Modal opens with current data pre-filled.
  3. Update values and click Save Changes.
  4. To reset PIN, click the key icon and submit a new unique PIN.

5) CCTV and Device Operations
  • CCTV: Manage camera index, camera sources JSON, and feed records.
  • Biometric: Register devices and maintain device status/location.
  • Payroll: Create weekly payroll rows and track payment status.
  • Cloud Sync: Configure cloud keys and monitor sync queues.
6) Troubleshooting Guide

Problem: Live feed is blank

  • Confirm camera is not in use by another app.
  • Check CCTV camera source configuration.
  • Restart app and retest built-in camera fallback.

Problem: Worker cannot clock in

  • Verify worker status is active.
  • Verify PIN is correct and still unique in system.
  • Ensure face is visible in camera for verification step.
