System Manual

Use this guide for onboarding workers, attendance operations, camera setup, and troubleshooting.

1) Worker Management
  • Open Workers page, click Add Worker, and fill in name, phone number, optional address, emergency contact, department, and unique PIN.
  • Worker IDs are auto-generated from Settings (prefix + digits).
  • Use Edit to update worker details later.
  • Use key icon to reset PIN. PIN must remain unique.
2) Attendance Workflow
  • Workers use login page with Worker ID and PIN.
  • System verifies credentials and captures a photo immediately.
  • Attendance page shows paired IN/OUT records with photos.
3) Cameras and Live Feeds
  • Dashboard displays live feeds for all configured camera sources.
  • Settings accepts camera source JSON for usb, bluetooth, ip, builtin.
  • If no camera sources are configured, built-in camera fallback is used.
4) Settings
  • Configure organisation name, worker ID format, camera sources, and optional Firebase storage values.
  • Keep camera JSON valid array format.
5) Troubleshooting
  • If live camera panel is black, verify camera source and ensure no other app is locking the camera.
  • If workers cannot clock in, check worker status is Active and PIN is correct.
  • If imports show unresolved warnings in editor, select the project .venv interpreter in VS Code.
