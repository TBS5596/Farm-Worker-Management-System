System Manual

Use this guide for onboarding workers, attendance operations, grouped data pages, and troubleshooting.

1) Worker Management
  • Open Workers page, click Add Worker, and fill in all configurable fields: full name, phone, emergency contact, NRC number, department, enrollment date, status, address, and unique PIN.
  • Worker IDs are auto-generated as a strict 4-digit series (0001, 0002, 0003...).
  • Use Edit to update any worker profile field later.
  • Use key icon to reset PIN. PIN must remain unique.
2) Attendance Workflow
  • Workers use login page with Worker ID and PIN.
  • System verifies credentials, captures a photo, and stores geolocation when available.
  • Attendance page shows paired IN/OUT records with photos.
3) CCTV Page
  • Open CCTV page from the sidebar to manage camera index and camera sources JSON.
  • Use Add CCTV Feed to register camera feeds.
  • If no camera sources are configured, built-in camera fallback is used.
  • The system maintains a default built-in camera entry in feed and recording tables.
4) Grouped Data Pages
  • Data Hub is the launcher for grouped components: CCTV, Biometric, Payroll, and Cloud Sync.
  • Biometric page covers device setup and links to biometric-related tables.
  • Payroll page supports payroll entry and payroll records.
  • Cloud Sync page contains Firebase configuration and sync queue/metadata views.
5) Settings and Users
  • Settings page is organisation-focused (for example organisation name).
  • Users page includes all configurable fields: username, full name, email, phone, role, and linked worker.
  • Password reset generates a new random password shown in a flash message.
6) Troubleshooting
  • If live camera panel is black, verify camera source and ensure no other app is locking the camera.
  • If workers cannot clock in, check worker status is Active and PIN is correct.
  • If imports show unresolved warnings in editor, select the project .venv interpreter in VS Code.
